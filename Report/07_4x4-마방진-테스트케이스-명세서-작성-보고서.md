## 2) 수행 배경

사용자 요청에 따라 이미지 기반 테스트 항목을 정리해 표준 템플릿 형식의
테스트케이스 명세서를 작성했고, 해당 산출물을 보고 체계에 맞춰 `Report`에
별도 보고 문서로 등록했다.

---

## 3) 수행 결과

### 3.1 생성된 산출물

- 테스트케이스 명세서(원본): `docs/TC_4x4_MagicSquare_테스트케이스_명세서.md`
- 보고서(본 문서): `Report/07_4x4-마방진-테스트케이스-명세서-작성-보고서.md`

### 3.2 테스트케이스 구성 요약

- 총 테스트케이스 수: 24건
- 분류 체계:
  - A군: 빈칸 탐지/순서 검증
  - B군: 마방진 판정(행/열/대각선)
  - C군: 누락 숫자 및 입력 규칙 검증
  - D군: 조합 해석/출력 계약 검증
  - E군: 오류 계약/화이트리스트 검증

### 3.3 템플릿 반영 항목

각 테스트케이스는 아래 필수 항목을 포함하도록 통일했다.

- 테스트 ID, 테스트 목적, 테스트 기능
- 입력값, 테스트단계, 테스트환경
- 전제 조건, 성공/실패 기준, 특별 절차
- 프로젝트/대상 시스템/작성·승인·문서 상태 메타데이터

---

## 4) PRD/요구사항 정합성

- PRD `AC-01` 입력 검증: 크기, 빈칸 수, 값 범위, 중복 검증 케이스 반영
- PRD `AC-02` 좌표/숫자 탐색: row-major 좌표, 누락 숫자 오름차순 반영
- PRD `AC-03` 조합/판정: 정순 우선, 역순 fallback, 실패 코드 반영
- PRD `AC-04` 오류 계약: 허용 코드 화이트리스트 및 메시지 계약 반영
- PRD `INV-07` 출력 계약: `int[6]` 및 1-index 좌표 검증 반영
